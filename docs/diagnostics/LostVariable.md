# Потерянное значение переменной (LostVariable)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

Присвоенное значение теряется, если ни один путь после записи не приводит к его чтению. Это бывает при повторном присваивании, в том числе в разных ветвях условия, и при лишней записи в конце метода. Чтение на следующей итерации, переход `Продолжить` и использование в обработчике исключения учитываются. Одиночную запись в переменную без обращений проверяет диагностика `UnusedLocalVariable`.

Правило также отмечает итератор, который перезаписывает переменную модуля, итератор внешнего цикла или саму переменную с обходимой коллекцией. Выделяется имя в заголовке внутреннего или конфликтующего цикла.

Параметр `checkFormShadowing` включает отдельную проверку объявления параметра метода или локальной `Перем` в модуле формы. Для совпадения требуется свойство, которое система типов разрешила у этой формы. По умолчанию проверка отключена.

## Примеры

```bsl
ДатаНачала = Заказ.ДатаНачала; // значение потеряно
ДатаНачала = Заказ.ДатаОкончания;
ЗаполнитьПериод(ДатаНачала, ДатаОкончания);
```

Во второй строке следует присвоить значение переменной `ДатаОкончания`. Если правая часть вызывает метод, при исправлении учитывайте его побочные эффекты.

```bsl
Для Каждого Строки Из Строки Цикл // Строки перезаписывается элементом
    Обработать(Строки);
КонецЦикла;

Для Каждого Строка Из Строки Цикл
    Обработать(Строка);
КонецЦикла;
```

Обычная запись реквизита формы или свойства объекта меняет состояние владельца. Анализ потерь отслеживает присваивания самим переменным. В модулях с загруженными метаданными дерево символов отделяет неявную локальную переменную от реквизита владельца.
