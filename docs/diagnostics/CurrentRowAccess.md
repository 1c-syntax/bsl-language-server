# Обращение к данным через ТекущаяСтрока динамического списка (CurrentRowAccess)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

Обращение к свойствам или методам через `ТекущаяСтрока` динамического списка вызывает чтение объекта из базы данных для каждой строки. Вместо этого следует использовать `ТекущиеДанные`, которые работают с уже считанными данными.

## Примеры

### Неправильно

```bsl
Значение = Список.ТекущаяСтрока.Наименование;
Список.ТекущаяСтрока.Записать();
```

### Правильно

```bsl
Значение = Список.ТекущиеДанные.Наименование;
```
