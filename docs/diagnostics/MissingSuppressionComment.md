# Подавление диагностики без пояснения (MissingSuppressionComment)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

Комментарий подавления диагностики (`// BSLLS:ИмяДиагностики-off` или `// BSLLS-off`) не содержит пояснения причины. Разработчики, читающие код позже, не понимают, почему диагностика была отключена и можно ли её вернуть.

Проверяются как отдельностоящие комментарии, так и комментарии в конце строки с кодом.

## Примеры

### Неправильно

```bsl
// BSLLS:DeprecatedMethodCall-off
Процедура СтарыйКод()

Сообщить("Текст"); // BSLLS:DeprecatedMethodCall-off
```

### Правильно

```bsl
// BSLLS:DeprecatedMethodCall-off — легаси, трогать нельзя до версии 3.0
Процедура СтарыйКод()

Сообщить("Текст"); // BSLLS:DeprecatedMethodCall-off — легаси, трогать нельзя до версии 3.0
```

## Особенности

- Пояснением считается любой непустой текст после директивы `-off`/`-выкл`; комментарии `-on`/`-вкл` не проверяются.
- Проверяются как русские (`выкл`), так и английские (`off`) формы.
- Диагностика сама **не подавляема**: в метаданных указано `suppressible = false`, поэтому комментарии `// BSLLS:MissingSuppressionComment-off` и `// BSLLS-off` не скрывают её замечания.
