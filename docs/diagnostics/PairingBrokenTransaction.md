# Нарушение парности использования методов "НачатьТранзакцию()" и "ЗафиксироватьТранзакцию()" / "ОтменитьТранзакцию()" (PairingBrokenTransaction)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

Начало транзакции и ее фиксация (отмена) должны происходить в контексте одного метода.

Диагностика не анализирует ветвления (`Если`, `Возврат`). Внутри метода она линейно считает две независимые пары вызовов:

* `НачатьТранзакцию` / `ЗафиксироватьТранзакцию`
* `НачатьТранзакцию` / `ОтменитьТранзакцию`

Два отката при одном `НачатьТранзакцию` дают срабатывание на втором вызове. Это ожидаемое поведение.

## Примеры

*Правильно*

```bsl
Процедура ЗаписатьДанныеВИБ()

    НачатьТранзакцию();

    Попытка
        ... // чтение или запись данных
        ДокументОбъект.Записать()
        ЗафиксироватьТранзакцию();
    Исключение
        ОтменитьТранзакцию();
        ... // дополнительные действия по обработке исключения
    КонецПопытки;

КонецПроцедуры
```

*Неправильно*

```bsl
Процедура ЗаписатьДанныеВИБ()
 
    НачатьТранзакцию();
    ЗаписатьДокумент();

КонецПроцедуры;

Процедура ЗаписатьДокумент()

    Попытка
        ... // чтение или запись данных
        ДокументОбъект.Записать()
        ЗафиксироватьТранзакцию();
    Исключение
        ОтменитьТранзакцию();
    ... // дополнительные действия по обработке исключения
    КонецПопытки;

КонецПроцедуры

```

*Неправильно — ранний откат внутри `Попытка`*

```bsl
НачатьТранзакцию();
Попытка
    Если НужноВыйти Тогда
        ОтменитьТранзакцию();
        Возврат;
    КонецЕсли;
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
КонецПопытки;
```

Ранний `ОтменитьТранзакцию()` внутри `Попытка` закрывает пару для `НачатьТранзакцию()`. Вызов в `Исключение` остаётся без пары, поэтому появляется сообщение «Отсутствует парный вызов "НачатьТранзакцию" для метода "ОтменитьТранзакцию"».

Не вызывайте `ОтменитьТранзакцию()` с последующим `Возврат` внутри `Попытка`. Если нужно прервать работу до фиксации, выбросьте исключение и откатите транзакцию только в `Исключение`.
