# Вызов общего модуля, недоступного в контексте вызова (CommonModuleIncompatibleCall)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

Где доступен общий модуль, определяют его флажки:

* на сервере виден модуль с флажком «Сервер»;
* на клиенте виден модуль с флажком «Клиент (управляемое приложение)» или «Вызов сервера».

Вызов модуля, которого в контексте вызова нет, не компилируется: «Переменная не определена», а для глобального
модуля - «Процедура или функция с указанным именем не определена».

Метод общего модуля, объявленный внутри инструкции препроцессора `#Если`, есть только там, где условие истинно.
Вызов такого метода из того же модуля в другом контексте - ошибка: без имени модуля он не компилируется, через
имя модуля (`Модуль.Метод()`) падает при выполнении с «Метод объекта не обнаружен». Диагностика проверяет оба
варианта по тексту модуля. Вызов из другого модуля (например, метода клиент-серверного модуля под `#Если Сервер` с клиента) дает
ошибку выполнения «Метод объекта не обнаружен»; такие вызовы пока не проверяются: текст вызываемого модуля может быть
не загружен.

Контекст вызова берется из директивы вызывающего метода (модули форм и команд), флажков общего модуля или вида
модуля (модули объектов и менеджеров - сервер) и окружающих инструкций `#Если`. Проверяются контексты сервера,
тонкого, веб- и мобильного клиента. Вызов под условием с символом операционной системы не проверяется.

## Примеры

#### Неправильно:
```bsl
// Модуль формы
&НаКлиенте
Процедура Заполнить(Команда)
    РаботаСФайлами.УдалитьВременныеФайлы(); // серверный модуль без флажка «Вызов сервера»
КонецПроцедуры
```

#### Правильно:
```bsl
// Серверный вызов - через модуль с флажком «Вызов сервера» или серверный метод формы
&НаКлиенте
Процедура Заполнить(Команда)
    РаботаСФайламиВызовСервера.УдалитьВременныеФайлы();
КонецПроцедуры
```
