## Описание диагностики

Сравнение, в котором литерал расположен слева от оператора (`Если 0 = Сумма`), а переменная или
выражение — справа, читается хуже привычной записи `Если Сумма = 0`: слева обычно ожидается
изменяемое значение, а не константа.

В отличие от языков с присваиванием в условии, в BSL нет риска случайно перепутать `=` и `==`,
поэтому единственная причина придерживаться такого порядка — читаемость. Диагностика предлагает
писать литерал справа.

## Примеры

Неправильно:

```bsl
Если 0 = Сумма Тогда
    // ...
КонецЕсли;

Если Истина = Флаг Тогда
    // ...
КонецЕсли;
```

Правильно:

```bsl
Если Сумма = 0 Тогда
    // ...
КонецЕсли;

Если Флаг = Истина Тогда
    // ...
КонецЕсли;
```

## Исключения

* Сравнение двух литералов (`Если 0 = 1 Тогда`) нарушением не считается: переставлять в нём нечего.
* Булевы литералы (`Истина`, `Ложь`) проверяются наравне с остальными. По таким сравнениям может
  дополнительно срабатывать диагностика `CompareWithBoolean`.
