# Имя функции не должно начинаться с "Получить" (FunctionNameStartsWithGet)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

В имени функции слово получить лишнее т.к. функция по определению возвращает значение.

## Примеры

Параметр `prefixes` задаёт список префиксов через запятую, например `"АЯ_, БСП_"`.
Проверка выполняется без учёта регистра для исходного имени и имени после одного из указанных префиксов.
Префиксы — обычный текст, не регулярные выражения. Пробелы вокруг элементов и пустые элементы игнорируются.
Пустое значение (по умолчанию) сохраняет проверку только исходного имени. Префиксы не удаляются последовательно.

При `"prefixes": "АЯ_"` функция `АЯ_ПолучитьВажныеДанные()` также вызовет замечание.
Правило проверяет слово `Получить`; английское `Get` не проверяется.

```bsl
// Не правильно: 
Функция ПолучитьИмяПоКоду()

// Правильно: 
Функция ИмяПоКоду()
```
