## Описание диагностики

Диагностика обнаруживает вызовы
`УстановитьПривилегированныйРежим(Истина)` или
`SetPrivilegedMode(True)` внутри экспортных процедур и функций.

Привилегированный режим отключает обычную проверку прав доступа
и может создавать риски безопасности.

Вызовы в неэкспортных методах, вызовы с параметром `Ложь`
и вызовы с переменными в качестве аргумента не учитываются.

## Примеры

Неправильно:

```bsl
Процедура ОбновитьДанные() Экспорт
    УстановитьПривилегированныйРежим(Истина);
КонецПроцедуры
```

Правильно:

```bsl
Процедура ОбновитьДанные() Экспорт
// Выполнение действий с обычной проверкой прав доступа.
КонецПроцедуры
```
