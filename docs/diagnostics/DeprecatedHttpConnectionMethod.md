# Устаревшие методы объекта HTTPСоединение (DeprecatedHttpConnectionMethod)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

В платформе 8.3.21 методы объекта `HTTPСоединение` объявлены устаревшими в клиентском контексте. Вместо них следует использовать асинхронные аналоги с суффиксом `Асинх`.

Асинхронные методы доступны только на клиенте. Диагностика определяет возможные контексты компиляции вызова (вид модуля и его метаданные, директиву метода, ветку препроцессора) и сообщает вызов, только если **все** они клиентские. Иначе предложенная замена не соберётся на серверной стороне.

Практически это означает:

* модули управляемого и обычного приложения — срабатывает;
* модули управляемых форм и команд — только методы с директивой `&НаКлиенте`; методы без директивы (платформа компилирует их на сервере) и методы с директивами `&НаСервере`, `&НаСервереБезКонтекста` и `&НаКлиентеНаСервере*` не сообщаются;
* модули обычных форм — весь код, так как директивы компиляции в них не применяются;
* общий модуль — весь код, если он компилируется только на клиенте; при флаге `Сервер` или `Внешнее соединение` диагностика не срабатывает;
* если метаданные общего модуля недоступны, клиентский контекст не подтверждён, и диагностика не срабатывает;
* серверные модули не анализируются.

## Устаревшие методы

- `ВызватьHTTPМетод()` → `ВызватьHTTPМетодАсинх()`
- `Записать()` → `ЗаписатьАсинх()`
- `Изменить()` → `ИзменитьАсинх()`
- `ОтправитьДляОбработки()` → `ОтправитьДляОбработкиАсинх()`
- `Получить()` → `ПолучитьАсинх()`
- `ПолучитьЗаголовки()` → `ПолучитьЗаголовкиАсинх()`
- `Удалить()` → `УдалитьАсинх()`

## Примеры

### Неправильно

```bsl
&НаКлиенте
Процедура ПолучитьДанные()
    Запрос = Новый HTTPЗапрос("/api/data");
    Соединение = Новый HTTPСоединение("example.com");
    Соединение.Получить(Запрос, Ответ);
КонецПроцедуры
```

### Правильно

```bsl
&НаКлиенте
Асинх Процедура ПолучитьДанные()
    Запрос = Новый HTTPЗапрос("/api/data");
    Соединение = Новый HTTPСоединение("example.com");
    Ответ = Ждать Соединение.ПолучитьАсинх(Запрос);
    ТелоОтвета = Ответ.ПолучитьТелоКакСтроку();
КонецПроцедуры
```
