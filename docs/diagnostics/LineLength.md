# Ограничение на длину строки (LineLength)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

При длине строки более 120 символов следует использовать переносы. Строки длиннее 120 символов делать не рекомендуется, за исключением тех случаев, когда перенос невозможен (например, в коде определена длинная строковая константа, которая выводится без переносов в окно сообщений с помощью объекта СообщениеПользователю).

## Параметры

### checkComments

Тип: `Булево`  
Значение по умолчанию: `Истина`

Анализировать длину строк комментариев (обычных комментариев, описаний методов и висячих комментариев).

При значении `Ложь` из проверки исключаются все комментарии, включая описания методов и висячие комментарии (в конце строки с кодом). В этом случае параметры `checkMethodDescription` и `excludeTrailingComments` не влияют на результат — их учет имеет смысл только при `checkComments = Истина`. Длинная кодовая часть строки при этом продолжает диагностироваться: диапазон замечания заканчивается на коде, а не на исключенном комментарии.

Пример настройки:

```json
{
  "LineLength": {
    "checkComments": false
  }
}
```
