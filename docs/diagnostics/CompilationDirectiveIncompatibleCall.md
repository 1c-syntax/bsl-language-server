# Вызов метода, недоступного в контексте вызывающего метода (CompilationDirectiveIncompatibleCall)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

Директива компиляции определяет, где метод модуля формы или команды компилируется, а значит, какие методы
того же модуля он может вызвать:

* клиентский метод (`&НаКлиенте`) недоступен при компиляции на сервере и внеконтекстным методам;
* контекстный серверный метод (`&НаСервере` или без директивы) недоступен внеконтекстным методам
  (`&НаСервереБезКонтекста`, `&НаКлиентеНаСервереБезКонтекста`).

Если метод вызывает метод, которого в его контексте нет, модуль не компилируется: «Процедура или функция с
указанным именем не определена». Для формы это значит, что она не открывается целиком.

Проверяются вызовы методов того же модуля по имени, в том числе внутри выражений. Вызовы через объект
(`ЭтотОбъект.Метод()`) платформа при компиляции не проверяет, диагностика тоже. Методы с директивой, недоступной
виду модуля, пропускаются - их отмечает диагностика `CompilationDirectiveNotAllowed`.

Инструкции препроцессора `#Если` учитываются: вызов проверяется в тех контекстах (сервер, тонкий, веб- и
мобильный клиент), где он компилируется по директиве вызывающего метода и условиям `#Если`, `#ИначеЕсли`,
`#Иначе` вокруг него. Например, в серверном методе вызов клиентского метода под `#Если Клиент` не компилируется и
не отмечается, а под `#Если Сервер` - отмечается. Внеконтекстный метод не видит клиентских и контекстных
серверных методов ни на клиенте, ни на сервере. Вызов под условием с символом операционной системы (`Linux`,
`Windows`, `MacOS`) не проверяется.

## Примеры

#### Неправильно (модуль формы):
```bsl
&НаСервереБезКонтекста
Функция ДанныеТовара(Товар)
    Возврат ПодготовитьДанные(Товар); // контекстный метод из внеконтекстного
КонецФункции

&НаСервере
Функция ПодготовитьДанные(Товар)
    ...
КонецФункции

&НаСервере
Процедура ЗаполнитьНаСервере()
    ОбновитьЗаголовок(); // клиентский метод из серверного
КонецПроцедуры

&НаКлиенте
Процедура ОбновитьЗаголовок()
    ...
КонецПроцедуры
```

#### Правильно:
```bsl
&НаСервереБезКонтекста
Функция ПодготовитьДанные(Товар)
    ...
КонецФункции

&НаКлиенте
Процедура Заполнить(Команда)
    ЗаполнитьНаСервере();
    ОбновитьЗаголовок();
КонецПроцедуры
```
